# utodo 完成烟花特效（短设计）

日期：2026-11-24
状态：待确认

## 意图

点圆圈（或标题）完成一件事时，要一眼看见「完成了一件事」。用户明确要**明显**的效果，不是角落里的小火花：彩纸炸开、满卡飘落、能让人注意到。

卡片是无边框透明面板，宽 268，四周只有 36pt 阴影边距，超出就被窗口裁掉。所以庆祝范围限定在卡片内，用密度、颜色和时长来做「明显」，而不是靠范围。

## 目标 / 非目标

- 目标：每次完成都有一次彩纸绽放；起爆点在被点的圆圈；持续约 0.9 秒；不挡鼠标、不影响录入和拖动；离屏预览能看效果；核心几何可单测
- 非目标：不做声音、不做独立特效窗口、不让粒子冲出卡片、不加配置开关、不用 CAEmitterLayer

## 方案与取舍

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| A. 卡片内 SwiftUI 粒子（Canvas + TimelineView） | 与现有 UI 同层，坐标好算，纯函数可单测，预览可渲染 | 范围到卡片边缘为止 | **选 A** |
| B. 独立透明特效窗口 | 能炸开 200pt，最张扬 | 多一层窗口生命周期（多屏、全屏层级、拖动跟随），预览渲染不到 | 不做；A 的粒子层将来可原样搬过去 |
| C. CAEmitterLayer 彩纸 | 原生性能、彩纸质感真 | 形状/调色不可控，和 SwiftUI 布局对齐要手算，预览与单测都抓不到 | 不做 |

选 A 的理由：这一版要「明显的庆祝」但零结构风险；粒子场是纯函数，既能单测也能在 `--render-preview` 里定格一帧，改样式不用靠真机反复点。

## 视觉规格

- **起爆点**：被点那一行圆圈的中心（x 固定 26pt，y 取该行实际 frame 的左中）。点标题完成也从圆圈起爆，保持「打勾」的一致语义
- **冲击环**：金色描边圆，0.25 秒内从 0.2 倍扩到 1.4 倍（半径 ~34pt）并淡出
- **彩纸**：52 颗，分两批（主爆 34 颗立刻、余爆 18 颗延迟 60–140ms）
  - 形状：细长矩形（1.6–3.2 × 4–7pt），少量小圆点当亮片
  - 初速按分量采样：横向 -70…200 pt/s（起爆点靠卡片左边，向左收窄避免一出生就被裁）、纵向 -170…-20 pt/s（合速度 20–260），方向上半圆；受重力 260 pt/s²，带轻微空气阻尼（卡片只有 200pt 高，重力再大粒子会在 0.3 秒内全掉出画面）
  - 自旋 ±540°/s，寿命 0.7–1.0 秒，最后 35% 时间淡出
  - 颜色：金 `#FFD479`、桃红 `#FF6B8A`、薄荷 `#6EE7C8`、亮蓝 `#6BB6FF`、暖白（各约 20%）
- **卡片脉冲**：整卡 `scaleEffect` 到 1.015，0.1 秒进、0.18 秒回，只是轻轻一顿
- **层叠**：粒子层压在文字之上、`allowsHitTesting(false)`、按卡片圆角裁剪
- **降级**：系统开了「减弱动态效果」时只做卡片脉冲 + 一次短暂金色描边高亮，不撒粒子

## 交互

- 一次成形动画约 1 秒；连点多个不叠加到失控，最多同时保留 3 组，超出丢弃最旧的
- 粒子层不参与命中测试，不挡圆圈、标题、删除按钮和拖动热区
- 删除、清除已完成、窗口拖动、透明度调节都不受影响

## 实现要点

- 新增 `UTodoCore/Fireworks.swift`（纯逻辑、可测）：
  - `FireworkBurst`（id、origin、seed、startedAt）
  - `Firework.particles(seed:)`：固定 seed 产生同一组粒子（数量、角度、速度、尺寸、颜色、延迟）
  - `Firework.position(particle:at:origin:)` / `opacity(...)` / `rotation(...)`：解析式求某时刻状态，不保存每帧数组
  - `Firework.lifetime`、`maxConcurrentBursts`
- `DesktopCardView`：
  - 行内用 `GeometryReader` + `PreferenceKey` 把每行 frame（卡片坐标系）记到 `@State`，点击时取该行左中作为 origin，随 `model.complete(todo, burstAt:)` 传入
  - 顶层叠 `ZStack`：粒子用 `Canvas` + `TimelineView(.animation)` 绘制；不在播放时整层不渲染
  - 播放结束由 `Task.sleep` 清掉对应 burst（和现有 `dissolving` 的清理方式一致）
- `CardViewModel`：`bursts: [FireworkBurst]`、`complete(_:burstAt:)`，移除后仍按原逻辑 `reload + postStoreChanged`；保留不带 origin 的 `complete(_:)` 供键盘/测试使用（默认起爆点取卡片中上部）
- `PreviewRenderer`：`UTODO_PREVIEW_BURST=1` 时注入一组定格在 30% 进度的 burst，便于 `--render-preview` 出图验收
- 单测（`Tests/UTodoCoreTests/FireworksTests.swift`）：
  - 同 seed 结果完全一致、不同 seed 不同
  - 数量 52、寿命在 0.7…1.0、延迟在 0…0.14、颜色都在配色表内
  - 0 秒时所有粒子都在原点附近，1 秒时全部透明度为 0
  - 粒子在寿命内最远不超出卡片左右边缘 120pt（视觉上由卡片圆角裁剪，但数学上不许飞太远）
  - 最多同时 3 组

## builder 自行决定

- 具体配色数值与粒子尺寸：上面已定，允许 ±10% 微调手感
- 冲击环半径、脉冲幅度：上面已定，以「明显但不眩晕」为准
- 完成后原行立刻消失（现状）还是先打勾再消失：维持现状，粒子负责交代「去哪了」
- 高亮/闪烁频率：不加频闪，避免廉价感
