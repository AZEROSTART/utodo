# utodo 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个常驻桌面右上角的玻璃待办卡片，加一个能直接写库的 `utodo` CLI，agent 写进去 1 秒内上屏。

**Architecture:** 一个 Swift Package，三个 target：`UTodoCore`（模型 + SQLite Store + 纯函数决策）被 `UTodoApp`（AppKit 面板 + SwiftUI 卡片）和 `utodo`（CLI）共用。CLI 与 App 不通过进程通信，直接读写同一个 SQLite 文件（WAL），写完后发 `DistributedNotificationCenter` 通知，App 收到刷新。

**Tech Stack:** Swift 6.3 / SwiftUI / AppKit（NSPanel）/ 系统 libsqlite3 / Swift Testing / Carbon `RegisterEventHotKey`

**Spec:** `docs/superpowers/specs/2026-11-24-utodo-design.md`

## Global Constraints

- 只支持 macOS 26.0+，Apple Silicon；`platforms: [.macOS("26.0")]`
- 卡片宽 268pt；正文 12.5pt / 行高 30pt；圆角 20pt；列表区最多 5 行后滚动
- 全屏退让时整卡 alpha `0.55`，过渡 `300ms`；悬停或输入时回到 `1.0`
- Bundle ID `com.azerostart.utodo`；`LSUIElement = true`（无 Dock 图标）
- 数据库固定路径 `~/Library/Application Support/utodo/utodo.sqlite3`，WAL 模式，`busy_timeout = 2000`；环境变量 `UTODO_DB` 可覆盖（测试与 E2E 用）
- 全局快捷键 `⌥Space`；不申请辅助功能 / 输入监控 / 屏幕录制任何权限
- 不写 `~/Library/LaunchAgents`；登录项只走 `SMAppService.mainApp`
- 短 id = UUID 前 8 位小写，唯一前缀匹配

## Review Focus

1. 空标题（手工输入回车、`utodo add ""`）——应被忽略，不产生空行，光标留在输入框
2. 超长标题（200 字中文、无空格）——单行省略号截断，不撑破 268pt 卡片、不换行
3. 数据库文件被删除或损坏——App 自动重建空库继续运行，不崩溃、不弹窗
4. CLI 与 App 同时写——WAL + busy_timeout 下不丢数据、不锁死、不出现重复行
5. 全屏误判——普通窗口最大化但未全屏时，卡片必须保持不透明

  ```swift
  public struct Todo: Identifiable, Equatable, Sendable {
      public let id: UUID
      public let title: String
      public let createdAt: Date
      public let completedAt: Date?
      public var isCompleted: Bool { completedAt != nil }
  }

  public enum TodoStoreError: Error, Equatable { case notFound, ambiguousPrefix, database(String) }

  public final class TodoStore: @unchecked Sendable {
      public static var defaultURL: URL { get }          // UTODO_DB 优先，否则 App Support
      public init(url: URL = TodoStore.defaultURL) throws
      public func add(title: String) throws -> Todo?     // 空标题返回 nil

      public func complete(idPrefix: String) throws -> Todo   // 已完成再调一次原样返回
      public func delete(idPrefix: String) throws -> Todo
      public func clearCompleted() throws -> Int
  }
  ```
  排序：未完成按 `createdAt` 倒序；已完成接在后面，按 `completedAt` 倒序。

**Interfaces:**
- Produces:
  ```swift
  public struct WindowSnapshot: Equatable { public var ownerPID: pid_t; public var bounds: CGRect }
  public enum FullscreenDetector {
      public static func isFullscreen(frontPID: pid_t, windows: [WindowSnapshot],
  ```

- 判据：前台进程有一个窗口的 `bounds` 覆盖 `screenFrame`（四边差值都在 tolerance 内）
